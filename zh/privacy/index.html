隐私说明

最后更新：2026-11-07

谁负责

Openshelf 是由 Xia Chen 运营的个人非商业项目，本页所述的数据处理由其负责（即 GDPR 所称的控制者）。

联系方式：在 GitHub 上提交 issue。如果你的请求涉及不想公开的个人信息，请提交一个只写明“有私人请求”、不含细节的 issue，我们会在那里商定私下联系的方式。

访问本站

本站托管在 GitHub Pages 上。你打开页面时，GitHub（荷兰的 GitHub B.V. 和美国的 GitHub, Inc.）会处理你的 IP 地址和常规请求信息，例如请求的页面、时间和浏览器，用于把页面发送给你。GitHub 说明它会出于安全目的记录访问者的 IP 地址。Openshelf 看不到这些日志。

法律依据：GDPR 第 6 条第 1 款 f 项，即安全提供网站的正当利益。GitHub 可能把数据传输到美国。它已通过欧盟-美国数据隐私框架（EU-U.S. Data Privacy Framework）认证，并同时使用欧盟标准合同条款。详见 GitHub 隐私声明。

Cookie 与浏览器存储

本站不设置 Cookie。字体、脚本和数据都来自本站。除此之外，网页只会连接我们自己的统计与投票服务器，详见下文。本站没有广告和社交媒体插件。

如果你在首页切换语言，这个选择会保存在浏览器的本地存储里，键名是 openshelf-lang。它只留在你的设备上。保存它是提供你所要求的功能所必需的（德国 TDDDG 第 25 条第 2 款第 2 项）。你可以随时在浏览器设置里删除它。

文章链接会带你去其他网站，那里适用各自的隐私政策。

访问统计

我们统计页面浏览和点击，以了解哪些文章被阅读，并改进网站。首页上的一个小脚本会把以下信息发送到我们的服务器：所在页面和语言；你从哪个网站来，只记录域名，例如 news.ycombinator.com；你在页面上的操作，例如打开了哪篇文章、它在列表里排第几、选择了哪个视图、筛选或主题，以及搜索了什么。同一次页面加载产生的记录共用一个随机数，它不会保存在你的浏览器里。

每次请求都会带上你的 IP 地址和浏览器标识（user agent）。它们不会被保存，只是和一个保密值以及当天日期一起，用来算出一个短代码，以便统计当天有多少个不同的访客。换一天就无法认出同一个访客。Cloudflare 会根据 IP 地址判断国家，我们保存这个国家。机器人不计入统计。

如果你的浏览器发送了 Do Not Track 或 Global Privacy Control 信号，脚本什么都不会发送。原始记录在 90 天后删除。

服务器是一个 Cloudflare Worker。Cloudflare, Inc.（美国）根据其数据处理协议代我们处理这些数据，数据库位于西欧。Cloudflare 已通过欧盟-美国数据隐私框架认证。法律依据：GDPR 第 6 条第 1 款 f 项，即在不识别访客身份的前提下了解网站使用情况的正当利益。

投票

你不需要账号就可以给文章投票。第一次投票时，浏览器的本地存储里会保存一个随机代码（键名 openshelf-voter）和你的投票（键名 openshelf-votes）。这样你可以修改或撤回投票，也不会被重复计算。你投票之前什么都不会保存（德国 TDDDG 第 25 条第 2 款第 2 项）。

我们的服务器保存文章、你的投票、随机代码经过加密变换后的形式，以及日期。为了防止滥用，服务器还会保存一个由你的 IP 地址和日期算出的代码，用来限制同一网络每天对同一篇文章只能投少数几票。这个代码一天后会被清除。你的 IP 地址本身不会被保存。各篇文章的票数在网站上公开显示。

再点一次同一个箭头即可撤回投票，服务器上的记录也会删除。除此之外，投票会一直保留。法律依据：GDPR 第 6 条第 1 款 f 项，即让读者表明哪些文章有用、同时防止操纵的正当利益。

提交与删除请求

提交网站和删除请求都通过 GitHub issue 进行。你在 issue 里写的内容是公开的，并适用 GitHub 的隐私声明。我们只把你发来的信息用于处理你的请求。法律依据：GDPR 第 6 条第 1 款 f 项。

文章与作者

Openshelf 收录公开发布在网站上的研究文章。来源包括各网站自己的订阅源、Hacker News（通过 Algolia 搜索接口）和 Rogue Scholar。我们的爬虫标识为 openshelf-crawler，并附有关于页的链接。

每篇文章我们保存标题、网址、网站、日期和主题，中英文简短摘要，Hacker News 上的讨论数，以及有哪些其他网站链接到它。我们不单独收集作者姓名，但姓名可能出现在网址、标题或摘要里。我们还保存一份已检查过的网址清单，避免重复检查同一篇文章。收录的条目会一直保留，直到有人要求删除。

为了判断一篇文章是否属于研究并撰写摘要，文章的公开文字会通过 OpenRouter（OpenRouter, Inc.，美国）发送给语言模型。发送的内容是文章简介和大约前 320 个词，判断回应关系时还包括链接前后的文字。OpenRouter 会再转给模型服务商，它们可能位于欧盟以外，例如美国或中国。发送的只有这些公开文字，不含任何访问者信息。

法律依据：GDPR 第 6 条第 1 款 f 项。目的是让发表在个人网站上的研究更容易被找到，并展示文章之间如何相互回应。我们只使用作者自己公开发布的内容，作者可以随时提出反对。

如需反对或删除，请提交删除请求。我们处理之后，该文章会从数据和网站上删除。如果你要求，我们也会停止收集你整个网站的内容。旧版数据仍留在公开仓库的历史记录里，如需一并删除，请告诉我们。

你还有权向数据保护监管机构投诉（GDPR 第 77 条），尤其是你居住或工作所在的欧盟成员国的监管机构。
